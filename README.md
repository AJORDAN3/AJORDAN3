# Ashleigh Jordan

**Petroleum Engineering at Colorado School of Mines · IT Engineering Intern at Liberty Energy · Expected graduation May 2027**

I build software for people whose main job happens somewhere other than a code editor. At Liberty, that meant turning spreadsheet data into a planning-system import. For the Mines SPE chapter, it meant making sure a volunteer who also checked in at the door only counted once. I like the part where understanding the work changes how I design the software.

## Selected work

**Field data importer** · I turned a repetitive data-entry workflow into a CSV-to-JSON import. Try a two-load manifest, then change one row to see how the importer handles a bad entry. [Read the build notes and run the example](https://github.com/ashleigh24jordan-ops/ashleigh24jordan-ops/blob/main/PROJECTS.md#field-data-importer)

**Chapter events and attendance** · I built a site for chapter officers to publish events, fill tabling shifts and measure attendance across a semester. The database tracks one record per person per event so two intake paths can feed the same report. [Explore the attendance model](https://github.com/ashleigh24jordan-ops/ashleigh24jordan-ops/blob/main/PROJECTS.md#chapter-events-and-attendance)

**Well-test interpretation** · I applied Python to a question from reservoir engineering: how fast does flowing pressure drop for each tenfold increase in elapsed time? The example reproduces the fitting step on synthetic data. [Inspect the calculation](https://github.com/ashleigh24jordan-ops/ashleigh24jordan-ops/blob/main/PROJECTS.md#well-test-interpretation)
