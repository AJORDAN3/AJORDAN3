# Add a project

Add a row to the skills table in PROJECTS.md and use this structure below it. Update the project count on the profile when adding an entry.

## Project name

Who used it? What did they do before? What did you personally build, and what changed for them? If a result is an estimate, explain the basis.

**Skills practiced.** Name each skill and the decision or feature that demonstrates it.

**For the next build.** Record the first thing you would repeat, one tradeoff and a mistake or delay you could avoid next time.

**Try the standalone example.** Link the smallest reusable file. Give a command, sample input, expected result and one change the reader can try.
