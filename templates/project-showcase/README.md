# Project showcase

Open index.html locally. Edit projects.js to add your own work. Refresh the page and type a skill into the filter. Publish the four web files together on any static host.

For a first run, replace the empty array with this fictional example:

```js
const projects = [{
  title: "Equipment checkout",
  problem: "The workshop had no shared list of borrowed tools.",
  decision: "Record one open checkout per tool.",
  result: "A repeat checkout was caught in a local test.",
  skills: ["Data modeling", "Testing"]
}];
```
