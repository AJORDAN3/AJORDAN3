# Reusable project templates

Download one ZIP, extract it, and open its README. For the GitHub profile, start with START-HERE.md. Each download includes editable source and permission to copy, modify, and redistribute it.

| Starter | What you can do | Download |
| --- | --- | --- |
| [GitHub profile and project log](github-profile/) | Introduce yourself and document decisions, evidence, and skills for each project. | [ZIP](https://raw.githubusercontent.com/AJORDAN3/AJORDAN3/main/templates/downloads/github-profile.zip) |
| [Personal dashboard](personal-dashboard/) | Load a daily schedule, task list, and inbox summary from a local JSON file. | [ZIP](https://raw.githubusercontent.com/AJORDAN3/AJORDAN3/main/templates/downloads/personal-dashboard.zip) |
| [Project showcase](project-showcase/) | Present project case studies in a searchable static page. | [ZIP](https://raw.githubusercontent.com/AJORDAN3/AJORDAN3/main/templates/downloads/project-showcase.zip) |
| [Event attendance](event-attendance/) | Record volunteers and check-ins and count unique participants across events. | [ZIP](https://raw.githubusercontent.com/AJORDAN3/AJORDAN3/main/templates/downloads/event-attendance.zip) |
| [Assistant toolkit](assistant-toolkit/) | Review an engineering decision and hand off work between assistant sessions. | [ZIP](https://raw.githubusercontent.com/AJORDAN3/AJORDAN3/main/templates/downloads/assistant-toolkit.zip) |
